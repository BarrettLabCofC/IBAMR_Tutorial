# Maintaining this repository

These instructions apply to AI agents making requested changes to the existing tutorial files and examples.

- Preserve the documented example behavior and keep commands, filenames, and links consistent when editing.
- Build applications against installed IBAMR using its exported CMake targets. Keep generated builds and simulation output under the build directory and out of Git.
- Preserve upstream copyright notices, COPYRIGHT, and source provenance in UPSTREAM.json.
- No fallback code. Report build or run failures directly; do not substitute a different example or fabricated output.
- Check changes as appropriate: links for documentation edits, and builds or runs for application changes. State which checks were actually performed.
